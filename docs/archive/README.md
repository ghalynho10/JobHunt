# Archive

These are pre-spec planning inputs, written before the specs that settled their decisions. They are kept because specs cite them as sources, so a reader can still see what a decision was built from. None of them is current: each has been superseded by [docs/specs/](../specs/), and where one disagrees with a spec, the spec wins.

- [`jobhunt-idea-brief.md`](jobhunt-idea-brief.md): the original idea brief, with the product statement, governing principles, v1 scope discipline and the JobPilot audit findings. Input to `/scope` and to spec 0001.
- [`jobhunt-carry-forward.md`](jobhunt-carry-forward.md): research findings recorded before the spec that would own them was written, each tagged with the feature that inherits it.
- [`app-shell-direction.md`](app-shell-direction.md): brainstorm output on the signed in app's page inventory, navigation and landing destination, taken to `/scope` and settled in spec 0008.
- [`feature-15-archetypes-and-pairs.md`](feature-15-archetypes-and-pairs.md): a working draft of the eval archetypes and ground truth pairs, built around a seniority rule the rubric does not have, and superseded by spec 0016.
- [`jobhunt-app-shell.html`](jobhunt-app-shell.html): a design tool export of the app shell screens (search, dense search, role detail, profile, applications), the visual mock up spec 0008 built toward.
