# JobHunt v1.0.0

_Declared complete 2026-09-17, released 2026-09-18_

The first complete version of JobHunt: enter a profile, search real listings,
see them ranked with the reasoning behind each verdict, apply, and have it
recorded, all working end to end on the live site. Free, with no billing.

## Highlights

- **Visible reasoning, not just a score.** Every listing is scored against
  your profile into one of five bands, from Strong match to Not a match,
  alongside the skills the posting mentions, the skills it doesn't, and a
  short explanation addressed to you.
- **A second AI checks the first.** A different model, from a different
  vendor, re-checks every skill the scorer claims to find in the same posting
  text. If it can't confirm a claim, that skill comes off your matched list
  and the card says so.
- **A public demo, no account needed.** [usejobhunt.dev/demo](https://usejobhunt.dev/demo)
  shows real Adzuna listings scored by the real scorer, against two candidate
  profiles that are clearly labelled fictional.
- **Applying is tracked automatically.** Clicking through to a posting opens
  the real listing on its own site. Marking it applied records it against
  your account and doesn't spend one of your weekly searches.

## Improvements

- **Your weekly limit, visible.** The search page now shows how many searches
  you've used this week against your cap.
- **Isolation enforced by the database.** One account can never read another
  account's profile, searches, or applications. Postgres enforces this
  directly, not the application's own code.
- **Scoring is checked before it ships.** Every change to the ranking model
  runs against a fixed set of example candidates and postings with known
  expected verdicts, catching a change that quietly makes scoring worse
  before it reaches you.
- **A fast off switch.** Every outside call this product makes can be
  switched off in one place, instantly, with no deploy needed, in case costs
  or a vendor issue ever demand a quick response.
- **No analytics, no tracking, no third party scripts.** Not a promise about
  intentions: the test suite fails if anyone adds a tracking package or a
  script tag pointing at another origin, verified by
  `src/features/legal/no-tracking.test.ts`.

## Fixes

- Fixed a posting with a single stated salary, not a real range, displaying
  as a range that repeated the same number twice (for example, "$109,440 to
  $109,440").

## Not in this release yet

v1 is the search to apply loop, kept deliberately narrow. A few things are
missing on purpose:

- Some listings can still appear more than once, and stray characters from
  the source text occasionally show up in a description as raw symbols. Both
  are confirmed on real listings and lead the next round of work.
- Search takes a title and a location only. Filtering by seniority, remote or
  hybrid, job type, salary range, or posting age isn't built yet.
- Marking a job applied doesn't ask how it went. A short set of follow up
  questions, and a dashboard summarizing your applications, come later.
